# NEXGEAR demo

## Cấu trúc
- index.html: cấu trúc trang.
- assets/css/style.css: giao diện và bố cục.
- assets/js/main.js: dữ liệu sản phẩm và tương tác.
- assets/images/: ảnh sản phẩm và banner.
- assets/images/sources.json: nguồn ảnh tham khảo.

Giải nén toàn bộ ZIP trước khi mở index.html. Giữ nguyên cấu trúc thư mục.

Đưa index.html và toàn bộ thư mục assets vào thư mục gốc repository GitHub. Bật GitHub Pages tại Settings > Pages, chọn Deploy from a branch và /(root).

Font chữ sử dụng Google Fonts và cần Internet; nếu ngoại tuyến, trang dùng font dự phòng. Ảnh đã lưu trong assets/images.

Tài khoản, giỏ hàng và chọn cấu hình là mô phỏng. Dữ liệu phiên mất khi tải lại trang. Không có đặt hàng hoặc thanh toán thực tế. Dùng thông tin giả khi đăng ký thử.
